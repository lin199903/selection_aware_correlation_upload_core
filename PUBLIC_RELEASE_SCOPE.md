# Public release scope — reproducibility-v1.0.0-rc1

Included: original author code from the verified v151.8 public base; frozen/derived machine-readable outputs needed to audit manuscript numbers; v152 extension summaries; author-generated figures; `selcorr` source; provenance/runtime metadata.

Excluded: raw GEO matrices; FinnGen/GWAS/MSigDB source resources; third-party article text/figures; submission correspondence; reviewer simulations; internal decision/freeze ledgers; superseded manuscript drafts; private local paths/credentials; and late cohort loader files that were not mounted in the RC build environment.

The release prioritises claim auditability without falsely representing non-redistributable or unavailable inputs as public.
