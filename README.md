# Selection-aware correlation reproducibility archive

# Selecting genes for agreement changes the null reference for transcriptomic correlation — reproducibility-v1.0.0-rc3

This reproducibility archive supports the manuscript “Selecting genes for agreement changes the null reference for transcriptomic correlation”. Public repository releases use an independent reproducibility version and do not track internal manuscript draft numbers.

The archive extends the verified historical core with liver-only MASLD–alcohol-associated hepatitis replay results, empirical-covariance recovery, independent cross-cohort evaluation, Figure 4 source data, and the `selcorr` R package source.

## Release status

**RC, not final.** The package and current extension outputs are staged for author/reviewer inspection. Before tagging `reproducibility-v1.0.0`, regenerate the release archive from a fresh checkout and add the final release URL/archival DOI when available.

## Core scientific object

The repository treats selected Pearson correlation as a post-selection statistic. If the same workflow helps construct the tested gene set, the correlation is interpreted against a reference generated by that construction rather than against a fixed-set zero-centred null.

## Reproducibility levels

- **Level 1: integrity/claim audit.** Run `python verify_release.py`.
- **Level 2: archived output audit.** Inspect the verified historical outputs plus `paper_extensions/source_data/`.
- **Level 3: source-data re-execution.** Retrieve third-party inputs under their original terms and use the public scripts/package machinery. Cohort-specific late MASLD–AH loaders are outside this public release boundary; this limitation is explicit.

Internal manuscript versions are recorded only as provenance in `SUBMISSION_SNAPSHOT.json` and `RELEASE_METADATA.json`; they are not repository or release identities.
