## Core scientific object

The repository treats the selected Pearson correlation as a post-selection statistic. If the same workflow helps construct the tested gene set, the correlation is interpreted against a reference generated by that construction rather than against a fixed-set zero-centred null.

## Reproducibility levels

- **Level 1: integrity/claim audit.** Run `python verify_release.py`.
- **Level 2: archived output audit.** Inspect the frozen v151.8 outputs plus `v152_extensions/source_data/`.
- **Level 3: source-data re-execution.** Retrieve third-party inputs under their original terms and use the public scripts/package machinery. Cohort-specific late MASLD–AH loaders are not included in this RC; this boundary is explicit rather than hidden.
