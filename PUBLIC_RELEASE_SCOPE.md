# Public release scope — reproducibility-v1.0.0-rc3

Included: original author code from the verified historical base; frozen/derived machine-readable outputs needed to audit manuscript numbers; current paper-extension summaries; author-generated figures; `selcorr` source; provenance/runtime metadata.

Excluded: raw GEO matrices; FinnGen/GWAS/MSigDB source resources; third-party article text/figures; submission correspondence; reviewer simulations; internal decision/freeze ledgers; superseded manuscript drafts; private local paths/credentials; and late cohort loader files outside the public release boundary.

Public repository structure and release identifiers are deliberately independent of internal manuscript draft numbers. Draft identifiers may appear only in provenance/snapshot metadata.

The release prioritises claim auditability without falsely representing non-redistributable or unavailable inputs as public.
